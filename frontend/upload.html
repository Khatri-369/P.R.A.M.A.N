How it works

Integrity starts here.

Each file receives a unique evidence ID and a SHA-256 fingerprint calculated from its contents.

The original fingerprint is stored as a reference. Future checks compare the stored file against this fingerprint.

Uploading also starts the chain of custody and records an audit event.
